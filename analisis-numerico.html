1. Eliminación Gaussiana con Pivoteo Parcial

Resuelve el sistema $Ax = b$ triangulando la matriz aumentada y aplicando sustitución regresiva.

La matriz aumentada es $[A \mid b]$.

2. Método Iterativo de Jacobi

Aproxima la solución iterando $x_i^{(k+1)} = \dfrac{1}{a_{ii}}\left(b_i - \sum_{j \neq i} a_{ij}\,x_j^{(k)}\right)$.

3. Newton-Raphson para Sistemas No Lineales (2×2)

Resuelve $F(x,y) = 0$ mediante $X^{(k+1)} = X^{(k)} - J^{-1}(X^{(k)})\,F(X^{(k)})$.

Sintaxis: ^ potencia, funciones sin(), cos(), exp(), log(), sqrt(). La Jacobiana se calcula por diferencias finitas.

4. Regresión Polinomial de Grado 2 (Mínimos Cuadrados)

Ajusta $y = a_0 + a_1 x + a_2 x^2$ a un conjunto de datos mediante las ecuaciones normales.
